Battle Royale

Everyone starts with the same HP (health points). Each round, students face random classmates on the same question. The fastest right answer wins; a wrong or slower answer costs 1 HP. The last hero standing wins.

Questions

Students see each definition and pick its term. The wrong answers are other terms from the set.

New question set

Import from a link: paste the link to a Wayground, Kahoot, Blooket or Gimkit quiz, or a Google Sheet, then click Import. Each import adds its questions to the set, so you can import several links into one set.

Start a sheet from the template: make a copy in Google Sheets (or download it for Excel). It has a picture column for the question and for every answer: paste a picture link there (a Google Drive link works). Surge Showdown uses the same template. A Wayground or Blooket spreadsheet works too.

Or paste rows straight from a sheet (select them, Ctrl+C, then Ctrl+V in the box), one question per line.
